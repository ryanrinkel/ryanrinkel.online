2025–present

Solo creator · MIT, source-available · claudotcode.com · github.com/Claudot-Code/claudot-pub

An AI pair-programmer for Godot 4.x: chat with Claude in the editor, control the scene tree, run tests, capture screenshots, and debug without leaving Godot.

  • Owned the entire developer experience end to end: onboarding flow, documentation, sample workflows, UX copy, marketing site, launch trailer, and visual identity.
  • Built the project with an agentic coding workflow of my own design — daily, hands-on experience with where Claude Code shines and where developers get stuck.
